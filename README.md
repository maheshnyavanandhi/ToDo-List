# Minimal Task Flow — To-Do List Application

A simple, fast, and responsive To-Do List Web Application built with plain HTML, CSS, and vanilla JavaScript.

## Features

- **Add & Manage Tasks:** Easily add, complete, and delete tasks.
- **Progress Tracking:** Real-time completion counter and visual progress bar.
- **Filter Tasks:** Toggle views between All, Active, and Completed tasks.
- **Persistence:** Keeps tasks saved across sessions using `localStorage`.
- **Clean UI:** Styled with high contrast and modern system typography (`Inter`).
